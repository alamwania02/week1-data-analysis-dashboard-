# Titanic Data Analysis Dashboard

## Project Objective

This project is a basic data analysis dashboard developed using Streamlit and Pandas. It allows users to explore the Titanic dataset through summary statistics, missing value analysis, and visualizations.

## Dataset

The project uses the Titanic dataset, which contains information about passengers such as age, gender, passenger class, fare, and survival status.

## Features

* Upload a CSV file or use the default dataset
* Preview the dataset
* Display the number of rows and columns
* Show column data types
* Generate statistical summary
* Display missing values
* Visualize data using a bar chart and a histogram

## Technologies Used

* Python
* Streamlit
* Pandas
* Matplotlib
* Git and GitHub

Install the required libraries:

```bash

```

## Running the Application

Run the following command:

```bash

```
